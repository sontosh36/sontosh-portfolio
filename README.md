# Sontosh Kumar Sarker | MERN Stack Developer

A modern, responsive developer portfolio built with **Next.js, TypeScript, and Tailwind CSS** to showcase my projects, technical skills, and development journey.

## 📌 Overview

Welcome to my personal portfolio! I'm a junior MERN Stack Developer passionate about building responsive, user-friendly, and scalable web applications.

This portfolio highlights my projects, technical expertise, and approach to modern web development. It features a clean interface, reusable components, smooth animations, and a dark/light theme for an enhanced user experience.

### ✨ Key Highlights

- Responsive design for desktop, tablet, and mobile devices
- Dedicated pages for projects and project details
- Technical skills and development journey sections
- Dark and light theme support
- Smooth animations powered by Framer Motion
- SEO-friendly metadata using Next.js
- Reusable and maintainable component architecture
